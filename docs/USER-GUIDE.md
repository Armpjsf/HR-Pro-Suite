# คู่มือใช้งาน HR Pro Suite

## พนักงาน

เข้าสู่ระบบด้วยบัญชีที่ HR แจ้ง หากเปิดหน้าไม่ได้ให้ลองโหลดใหม่และตรวจอินเทอร์เน็ตก่อน หากบัญชีถูกระงับให้ติดต่อ HR

- **ลงเวลา:** เลือกสำนักงานหรือนอกสถานที่ เปิด GPS รอพิกัดและผลยืนยัน อย่ากดซ้ำเมื่อเครือข่ายช้า ตรวจสถานะวันนี้ก่อนลองใหม่ หากอยู่ข้ามสาขาให้เลือกวิธีตามที่บริษัทอนุญาต WFH ยังไม่ได้เปิดใน workflow นี้
- **ลา:** เลือกประเภท วันที่ และเต็มวัน/ครึ่งเช้า/ครึ่งบ่าย ระบบคำนวณตามตารางงานและวันหยุด ครึ่งวันใช้วันที่เดียวกัน ข้ามปีให้แยกคำขอ สิทธิ์จะคิดรวมใบลาที่รออนุมัติ ฟอร์มร่างเก็บชั่วคราวใน sessionStorage ไม่ใช่ใบลาที่ส่งแล้ว
- **คำขอเอกสาร:** ระบุประเภทและวัตถุประสงค์ รอ HR อนุมัติแล้วจึงเปิดฉบับออกจริง ข้อมูลเอกสารฉบับนั้นจะคงเดิม หากต้องแก้ให้ยื่นคำขอใหม่ เอกสารเก่าที่ไม่มี snapshot ต้องติดต่อ HR
- **เงินเดือน:** ตรวจโบนัสและคืนค่าใช้จ่ายแยกกัน ยอดที่แสดงคือข้อมูลจากงวดในระบบ หากยอดไม่ตรงให้แจ้ง HR พร้อมงวดและเลขรายการ ห้ามใช้การแจ้งเตือน LINE เพียงอย่างเดียวแทนหลักฐานโอน
- **ปฐมนิเทศ:** แสดงรายการที่ HR มอบหมายจริง หากไม่มีรายการ ให้ติดต่อ HR สถานะเสร็จต้องมาจากรายการในระบบ
- **สวัสดิการ:** หน้าแอพเป็นข้อมูลทั่วไป ต้องตรวจสิทธิ์ วงเงิน และเงื่อนไขเฉพาะรายกับ HR
- **สลับกะ:** ยังใช้การประสานหัวหน้าตามช่องทางบริษัท หน้าแอพไม่ได้ยื่นคำขอให้อัตโนมัติ
- **เพิ่มเติม:** ค้นหาเมนูด้วยชื่อ เช่น เอกสาร สลิป อบรม; กดออกจากระบบเมื่อใช้เครื่องร่วมกัน

## หัวหน้า

ใช้ปุ่มตรวจคำขอลูกทีมในหน้าหลัก หรือเมนูเพิ่มเติม ตรวจช่วงเวลา เหตุผล และผลกระทบก่อนอนุมัติ สิทธิ์อนุมัติในแอพจำกัดลูกทีมตาม manager_id ของ users หัวหน้าอนุมัติขั้นต้นแล้ว HR พิจารณาขั้นสุดท้าย หากบุคคลไม่อยู่ในทีม ให้ HR แก้สายบังคับบัญชาตามจริง

## HR

- ตรวจงานรออนุมัติและข้อมูลผิดปกติ แยกหัวหน้าอนุมัติออกจาก HR อนุมัติ
- ใบลาที่ดำเนินการแล้วไม่แก้/ลบผ่านตารางทั่วไป การกลับรายการประวัติต้องผ่านขั้นตอนที่ตรวจยอดครบ
- Bulk action แสดงรายการล้มเหลวและคงการเลือกไว้ให้ ตรวจสาเหตุก่อนลองเฉพาะรายการนั้นอีกครั้ง
- ฟอร์มที่แก้แล้วแต่ยังไม่บันทึกจะเตือนก่อนปิด ระหว่างบันทึกให้รอผล
- คลังเอกสารแยกสถานะไฟล์กับสถานะดัชนี AI ถ้าอ่านไม่ได้หรือเตรียมข้อมูลไม่สำเร็จ ให้ตรวจไฟล์/รหัสผ่าน/ผู้ให้บริการแล้วอัปเดตข้อมูลใหม่
- หนังสือรับรอง: ตรวจข้อมูลบริษัท เงินเดือน ตำแหน่ง และผู้ลงนามก่อนอนุมัติ ฉบับที่ออกแล้วต้องเก็บเนื้อหาเดิม

## Payroll

1. ตรวจเงินเดือนฐาน ประเภทจ้าง เวลา ลา OT และเบิกจ่ายที่อนุมัติแล้ว
2. คำนวณงวดและตรวจผลรายพนักงาน รายการที่ไม่สำเร็จยังไม่พร้อมจ่าย
3. ตรวจยอดรวม รายได้/เงินคืนค่าใช้จ่าย/รายการหักและค่า override
4. หากข้อมูล OT/เบิกจ่ายเปลี่ยน ให้คำนวณใหม่ก่อนยืนยันจ่าย
5. บันทึกยืนยันจ่ายในระบบเมื่อได้ตรวจหลักฐานตามขั้นตอนบริษัท ระบบนี้ไม่ได้โอนเงินให้เอง
6. การส่ง LINE เป็นการแจ้งเตือนแยกจากการจ่าย ส่งไม่สำเร็จไม่เปลี่ยนสถานะจ่ายแล้ว
7. สลิป paid ถูกล็อก การปรับย้อนหลังต้องมีผู้รับผิดชอบและหลักฐาน ไม่ปลดล็อกด้วยการแก้ช่อง status
